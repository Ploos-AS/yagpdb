# YAGPDB container v0.1.0

Initial Ploos AS stable container release for YAGPDB.

## Included

- YAGPDB v2.83.1 pinned to commit `7d2a3ba8975a4d0b30c814ada06ca43a969d7348`
- Go 1.26 build
- Alpine runtime
- non-root UID/GID 1000
- reverse-proxy-first HTTP deployment on port 5000
- PostgreSQL 17
- Valkey 8 with AOF persistence
- Docker Compose and rootless Podman Quadlet examples
- multi-architecture publication for linux/amd64 and linux/arm64
- BuildKit SBOM and provenance
- MIT packaging and upstream licensing

## Image

`ghcr.io/ploos-as/yagpdb:0.1.0`

Release promotion is allowed only after static validation, image build and smoke tests pass.
